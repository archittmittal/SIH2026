# 📚 Research and References

The foundation of VarshaMitra is built upon rigorous scientific research and verified data sources. Below is a curated list of academic literature, government data portals, and open-source frameworks that validate our technical approach.

## 🔬 Academic References

## 🌐 Government & Institutional Data Sources

*   **India Meteorological Department (IMD) Pune:** High-resolution gridded daily rainfall data (1901-present). [https://imdpune.gov.in/](https://imdpune.gov.in/)
*   **National Centre for Medium Range Weather Forecasting (NCMRWF):** IMDAA regional reanalysis. [https://www.ncmrwf.gov.in/](https://www.ncmrwf.gov.in/)
*   **Copernicus Climate Data Store:** ERA5 Hourly data on single levels. [https://cds.climate.copernicus.eu/](https://cds.climate.copernicus.eu/)
*   **NASA Global Precipitation Measurement (GPM):** IMERG V06 data. [https://gpm.nasa.gov/data/imerg](https://gpm.nasa.gov/data/imerg)
*   **NOAA Climate Prediction Center:** MJO, ENSO indices. [https://www.cpc.ncep.noaa.gov/](https://www.cpc.ncep.noaa.gov/)

## 🛠️ Open Source Tools & Frameworks

*   **PyTorch Geometric (PyG):** Core library utilized for implementing Spatio-Temporal GNNs.
*   **IndicTrans2:** State-of-the-art open-source translation model by AI4Bharat for accurate translation into 12+ Indian languages.
*   **FastAPI:** High-performance async web framework for Python.
*   **PostGIS & TimescaleDB:** Spatial and time-series extensions for PostgreSQL to handle meteorological geospatial data.
*   **Leaflet.js:** Lightweight open-source library for mobile-friendly interactive maps.
